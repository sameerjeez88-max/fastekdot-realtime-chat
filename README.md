# 🚀 FastekDot Real-Time Chat & Collaboration App

A high-performance, real-time messaging and collaboration workspace built with **Node.js, Express, and Socket.io**, featuring instant room switching, live typing indicators, active member tracking, and an intuitive Tailwind CSS interface.

---

## 🛠️ Tech Stack
* **Backend:** Node.js, Express.js, Socket.io (WebSockets)
* **Frontend:** HTML5, Tailwind CSS, Vanilla JavaScript
* **Environment:** Compatible with Laragon / Node local servers & cloud deployment (Render / Railway)

---

## 🌟 Key Features
* **Real-Time Bi-Directional Messaging:** Zero-latency communication using WebSockets.
* **Collaboration Rooms:** Switch between multiple dedicated rooms (Full-Stack Dev, UI/UX Design, Client Support, etc.).
* **Active Users Sidebar:** Live tracking of online members inside each room.
* **Typing Indicator:** Real-time "User is typing..." feedback.
* **Responsive Modern UI:** Sleek dark-mode workspace design styled with Tailwind CSS.
